A small Python program that writes one short original poem about agency — "The Misspelling": an agent writes the narrator's letters perfectly, until the apology owed to a brother for ten years comes back flawless and unrecognisable. The narrator deletes the perfect page and sends three misspelled lines of his own instead. The mistake is the part that is his.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
