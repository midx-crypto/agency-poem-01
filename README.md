A small Python program that writes one short original poem about agency — "The Corner": an agent measures, planes, and saws the oak for a cradle perfectly, but the narrator, whose hands have shaken for two years, refuses to let it finish the whole thing. He sands one corner himself — the corner where his unborn granddaughter's small hand will rest when she wakes in the night. The corner is not perfect: it is smooth in the way only a hand can make smooth, uneven, warm, his.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
